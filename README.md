# density
Terminal painting tool for unix-based OS.

**available tools**
- colors : white, black, red, blue, green, yellow, purple, cyan
- symbols : #, $, -, |, /, ', @, %, *, ~, <, >, ?, !, ., :, ;
- effects : standard, blinking, bold, underline, striketrough

**keybinds**
- F1 : switch color
- F2 : switch symbol
- F3 : switch effect

- CTRL + X : quit program
- CTRL + R : remove drawing

- enter : new line without restoring spaces
- backspace : remove previous character
- space : overwrite front character with space

- up arrow : move on previous line and store spaces
- down arrow : move on one line and store spaces
- right arrow : move on front character without overwriting
- left arrow : move on previous character without overwriting

**install**

- download the install script
- run it using command : `bash installation.sh` (if your not in the same folder, replace 'installation.sh' with path)
- now you can use command : `density` and without warning `density no_warning`

**support**

- Wont work on operating-systems that aren't unix-based.
- Tested on ptyxis terminal, fedora 44.
